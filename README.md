# Automated Excel Sales Analytics Pipeline

## 📌 Project Overview
This project demonstrates an automated data analytics workflow integrating **Microsoft Excel** and **Python**. It automates data extraction, processes sales transactions, and generates key business insights regarding top-performing products, sales representatives, regional sales distribution, and profitability margins.

---

## 🛠 Tech Stack & Tools
* **Excel:** Data Storage, Pivot Tables, Formulas & Analytical Models
* **Python:** Pandas (Data Wrangling), Matplotlib/Seaborn (Data Visualization)
* **IDE:** VS Code / Jupyter Notebook

---

## 📊 Key Insights & Analytics
1. **Sales Performance:** Identified top revenue-generating products and peak transaction months.
2. **Salesperson Analytics:** Evaluated individual sales performance to identify top revenue drivers.
3. **Regional Analysis:** Mapped city-wise sales performance to highlight high-value target markets.
4. **Margin Evaluation:** Analyzed product profitability against sales volume to flag low-margin high-volume items.
